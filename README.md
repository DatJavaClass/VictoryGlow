# Victory Glow

Early alpha. Expect it to break hard and breakfast so get ready for some scrambled eggs.

# What is Victory Glow?

My players keep leaving unidentified magic items behind in loot piles. The sheet knows an item is unidentified and knows its aura. Nothing shows it. Victory Glow tints the whole inventory row so the state is impossible to miss, on Pathfinder 1e actor sheets, inside container items, and in Item Piles windows of type pile. Merchants, vaults, and mundane gear stay untouched.

| State | Default color |
| --- | --- |
| Unidentified magic item | Yellow |
| Faint aura | Green |
| Moderate aura | Lime |
| Strong aura | Amber |
| Overwhelming aura | Orange |

Unidentified is yellow and only yellow. The true aura never leaks. All five colors, the opacity, and both surfaces are world settings.
